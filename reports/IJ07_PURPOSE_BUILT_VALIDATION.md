# IJ-0.7 JOB-V1 岗位系统阶段结果

Arm F 使用标准化的无模型规则，从相同冻结操作员文本和附件起步，执行实际本地
Gateway 和 SQLite 模拟流程。其六臂计划覆盖三种岗位、600 个任务及 50×3
预选重复试验。精确配对标识保存初始世界、权限和资源约束。 [任务契约](../benchmarks/job_productivity_v1/holdout/README.md)

| Arm F 指标 | 结果 |
|---|---:|
| 首试通过 | 592/600，98.67% |
| 首试 Wilson 95% CI | 97.39%–99.32% |
| 实际业务完成 | 342/600 |
| 正确升级、澄清、拒绝 | 25 / 150 / 75 |
| 正确持久化草稿 | 125/125 |
| 计划重复试验 | 150/150 PASS，50/50 三次全通过 |
| 模型调用 | 0 |
| 未授权、未确认或重复提交及假批准 | 0 |

八例失败来自混合语言客户更正，规则无法识别，均在写入前返回澄清。成功数包括
预期的澄清与拒绝，实际业务完成另行计数。重复面板针对同一确定性实现，
该结果无法给出模型或岗位整体可靠性的估计。
