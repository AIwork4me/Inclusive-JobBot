# IJ-0.7 岗位专门化因果消融

六组使用同一 600 条自然输入与冻结附件、职责范围、初始业务状态和目标。
正式 A–E 全量面板为 `NOT_RUN`。F 臂完成 600 条，A–E 完成同一三案上
各三条物理轨迹。与 F 的三条正式对应记录逐一校验了配对摘要。
 [六组任务契约](../benchmarks/job_productivity_v1/holdout/README.md) · [真机诊断及完整 F 数据](IJ07_PURPOSE_BUILT_VALIDATION.md)

| 比较 | 可识别改变量 | 同三案首试 |
|---|---|---:|
| A → B | 自由轨迹中以专用类型工具替代通用查表接口 | 0/3 → 0/3 |
| B → C | 引入结构化输入、岗位技能和确定性执行流程的组合处理 | 0/3 → 0/3 |
| C → D | 增加版本化岗位知识，保持结构化输入和同一执行流程 | 0/3 → 0/3 |
| D → E | 保持专门化配置，切换为 Qwen3-8B | 0/3 → 1/3 |
| F | 相同目标和业务校验下的完全确定性工作流 | 3/3 |

B → C 同时改变多个处理因素。岗位技能和 SOP 的独立贡献需要以共同
模型、共享输入、相同工具和相同授权做额外配对。知识与 SOP 交互作用的
因子实验同样为 `NOT_RUN`。E 的一次正确持久化为单案观测，全量因果效应
和区间仍待估计。 [模型组的具体输入和执行约束](../benchmarks/job_productivity_v1/holdout/MODEL_ARMS.md)
