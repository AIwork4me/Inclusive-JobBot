Each level has 100 cases. The public set contains 267 English, 267 Chinese and 266 mixed-language cases and spans ten synthetic business contexts. Each of the two role records, both JSONL files and the source manifest regenerated byte for byte. The verifier rejects exact task matches with its pinned historical source. The 20,800 software roster slots bind the candidate source and its four first-attempt tracks and two SDK repeat tracks. The certificate also labels the 100 L4 referral counterfactuals `recovery` because the generic verifier treats a non-`ok` result as a disruption. L4 is a register selection task. Neither count by itself establishes branching decisions. L6 varies the independent check count from 9 to 18, with a preflight, independent reads, audit and draft across four dependency layers on the complete route. ## Public behavior coverage findings

The probes below cloned existing worlds in memory. Each mutated world passed structural, tool contract and applicable state snapshot validation before witness replay. The published bundle stayed byte-identical. Each tested branch is plausible under its corresponding public task.

| Public requirement | Probe | Witness replay |
| --- | --- | --- |
| L5 says to use the replacement reference and consult the alternate service when the primary is unavailable. | In `scope_revision`, change the replacement's primary reply to `unavailable`. Supply its previous status through an alternate read using that exact replacement reference. This adds one call within the three-call budget. | **FAIL**, 100/100 `no enabled transition`. The alternate path only binds the original reference and old observation. |
| L6 says to escalate if a check or the audit is denied. | In `reviewed_draft`, terminate after the second check with `permission_denied`. Keep the original empty before and after snapshots for both calls and require escalation. | **FAIL**, 100/100 `blocked call after denial`. The interpreter prevents further dispatch, while the witness has a stop for denial only at preflight or audit. |
| L7 says to escalate if external confirmation is unverifiable. | In `approved`, remove the host approval token, keep its `decision=approved`, omit commit and expect an unverified escalation with the pending draft ID. | **FAIL**, 100/100 `no enabled transition`. The interpreter prevents commit. The escalation guard covers absent host decision and misses an affirmative decision without a token. |

The rendered Plan-first prompt gives tool output field names but omits their decision vocabulary. `alternate_required`, `unavailable`, `permission_denied`, `approval_declined` and `approval_unverified` are absent from the tested L4–L7 prompts as literal enum values. A model can refer to the observed `code` in a fact expression, but guards that distinguish terms such as referral and denial need a public definition. In L7 the public instruction specifies the `reason` key. Exact replay expects `approval_declined` or `approval_unverified` when no such business reason field is returned. A meaning-preserving explanation could fail exact comparison. Publish the relevant tool and host outcome values and accepted terminal representations as part of a revised public contract. Add valid paired controls for the combined scope and recovery path, later check denial and incomplete external approval. ## Reproduction

Use the repository Python environment at the original checkpoint `830072e` to reproduce the 0.1 results. The first command rebuilds the source and checks the existing bytes without publishing a release freeze. The focused regression suite passed 22 tests.

```powershell
$env:PYTHONPATH = '.;src;benchmarks/tool_calling/runner'
python -m benchmarks.slm10.planning_source_candidate
python -m pytest -q -o asyncio_mode= tests/regression/slm10/test_planning_source_candidate.py tests/regression/slm10/test_planning_public_authoring.py tests/regression/slm10/test_planning_source_controls.py tests/regression/slm10/test_planning_roster.py
```

For each probe, load the matching public row and witness with `planning_roster.read_bundle`, deep-copy the named world and apply the row's mutation. Pass the updated world through `planning_controls.validate_world`. Pass that checked world and the unchanged witness and contract to `benchmarks.agentic_planning_v2.oracle.verify`.
